Every pane runs on its owner's machine.

p2pmux is a terminal multiplexer for two or more people. You share a layout, not a computer: each pane's shell runs on the machine of whoever created it, under that person's PATH, environment and credentials.

Install

curl -fsSL https://p2pmux.com/install.sh | sh

macOS and Linux, Apple Silicon, Intel and arm64. The script is served as plain text — read it first. It downloads a binary and its SHA256 from GitHub Releases, checks the hash, and copies one file into place.

Linux builds need glibc 2.35 or newer — Ubuntu 22.04, Debian 12, Fedora 36 and up. A musl system builds from source.

Or with Homebrew, on either platform:

brew tap pelazas/tap
brew trust pelazas/tap
brew install p2pmux

Homebrew 6 will not load a formula from a third-party tap until you trust it, so the middle line is not optional there. On Homebrew 5 that command does not exist — skip it.

Or build it yourself:

cargo install --git https://github.com/pelazas/p2pmux --locked

Use

p2pmux create                # you host; Ctrl+S shows the line to send
p2pmux join 4KP7Q-M2XRW      # them, on their own machine

Ctrl+S copies that second line ready to paste; ten characters is the whole invite. Ctrl+P then arrows for panes, Ctrl+T for tabs, Ctrl+Q to leave the session running.

What that buys you

  • Start an agent in your pane, on your subscription. A teammate can take control and drive it without ever holding your API key.
  • They host panes too. Same session, their machine, their credentials.
  • Direct peer-to-peer when the network allows, relayed when NAT says no. Encrypted either way, and the status bar tells you which path you are on.
This is a trusted shared shell. Whoever holds a pane can run commands as that machine's user and read anything that user can read — including printing a secret to the screen.
